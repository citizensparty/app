Run a host

Keep a copy of the record.

Citizens Party has no headquarters server. Members run small computers, called hosts, that each keep a full copy of every proposal and vote and share it with members' apps. If any one host goes offline or is shut down, the rest still have everything.

  • Download, double-click, done. No settings, no accounts, no ports to open.
  • A host can't cheat. Every vote is signed on the member's phone, and apps check every one.
  • Small and cheap. A home PC, a laptop that stays on, a Raspberry Pi or a $5 server.
Download

About two minutes.

Every download lists its SHA-256 fingerprint, so you can check it arrived intact. All of them: {{SUMS}}.

{{HOSTWIN}}
  1. Open the downloaded citizens-host-windows.zip and click Extract all, then Extract.
  2. In the folder that opens, double-click citizens-host.exe.
  3. Windows will probably show a blue box: "Windows protected your PC." Click More info, then Run anyway. It warns because the program isn't signed yet (signing costs money, and we're working on a free way), not because anything is wrong with it.
  4. If Chrome stops the download first, click the download, then Keep (or Download suspicious file).
  5. Leave the window open. It shows how many members are connected. Closing it stops the host.
  6. Optional: start it automatically. Press Win+R, type this, press Enter, and put a shortcut to the program in the folder that opens:{{CMD_STARTUP}}

There's no Mac program yet, so it runs in Docker.

{{COMPOSE}}
  1. Install Docker Desktop if you don't have it.
  2. Put the file in a new folder, open a terminal there and start it:{{CMD_COMPOSE}}
  3. The live status screen:{{CMD_COMPOSE_STATUS}}
  4. To update:{{CMD_COMPOSE_UPDATE}}

Keep it running

Once it's up.

Your data

Your records and your host's key are kept in the data folder next to the program. the data folder next to docker-compose.yml, so updates keep them. /var/lib/citizens-host (by hand: the data folder next to the program). Back it up if you move computers.

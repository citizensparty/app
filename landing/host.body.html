Run a host

Keep a copy of the record.

Citizens Party has no headquarters server. Members run small computers, called hosts, that each keep a full copy of every proposal and vote and share it with members' apps. If any one host goes offline or is shut down, the rest still have everything.

We're in open beta, so setup takes a few more steps than it will later.

  • Download, double-click, done. No settings, no accounts, nothing to install. It finds the other hosts, copies the record and puts itself online through a free Cloudflare tunnel, so you don't open any ports and your home address stays private.
  • A host can't cheat. Every record is signed on a member's phone. A host can't change or invent a vote, and members' apps check every signature themselves.
  • The network checks every host. Before a new host is listed, the other hosts make sure it really holds the record. One that stops working is dropped, and members' apps test every host they use.
  • Small and cheap. A home PC, a laptop that stays on, a Raspberry Pi or a $5 a month server is plenty.
Download

About two minutes.

Every download lists its SHA-256 fingerprint, so you can check it arrived intact. All of them: {{SUMS}}.

Windows

{{HOSTWIN}}
  1. Open the downloaded citizens-host-windows.zip and click Extract all, then Extract.
  2. In the folder that opens, double-click citizens-host.exe.
  3. Windows will probably show a blue box: "Windows protected your PC." Click More info, then Run anyway. It warns because the program isn't signed yet (signing costs money, and we're working on a free way), not because anything is wrong with it.
  4. If Chrome stops the download first, click the download, then Keep (or Download suspicious file).
  5. Leave the window open. It shows how many members are connected. Closing it stops the host.

A Linux server

On a cloud server or a Raspberry Pi, one command installs it as a service that starts itself after a reboot:

{{CMD_INSTALL}}

Prefer to read it first?

{{CMD_READFIRST}}

Run it again to update. This shows the live status screen:

{{CMD_STATUS}}

Linux, by hand

{{HOSTLINUX}}
  1. Unpack it:{{CMD_TAR}}
  2. Start it:{{CMD_RUN}}
  3. Leave it running. It shows how many members are connected. Ctrl+C stops it.

Docker: Mac, Windows, Linux

There's no Mac program yet: on a Mac, use Docker. It works the same on Windows and Linux.

{{COMPOSE}}
  1. Put the file in a new folder, open a terminal there and start it:{{CMD_COMPOSE}}
  2. The live status screen:{{CMD_COMPOSE_STATUS}}
  3. To update:{{CMD_COMPOSE_UPDATE}}

The record and your host's key stay in the data folder next to the file, so updates keep them.

Keep it running

Once it's up.

Your data

Your records and your host's key are kept in the data folder next to the program (on a server: /var/lib/citizens-host). Back it up if you move computers.
